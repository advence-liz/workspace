# 01 - 快速开始

## 📝 目标

- 配置开发环境
- 获取 OpenAI API Key
- 完成第一个 API 调用
- 理解基本概念

## 🔑 获取 API Key

### 方法 1: OpenAI 官方

1. 访问 [OpenAI Platform](https://platform.openai.com)
2. 注册/登录账号
3. 进入 [API Keys](https://platform.openai.com/api-keys) 页面
4. 点击 "Create new secret key"
5. 复制并保存（只显示一次）

### 方法 2: Azure OpenAI（国内推荐）

1. 申请 Azure 账号
2. 创建 Azure OpenAI 资源
3. 获取 Endpoint 和 API Key

## 🛠 环境配置

### 1. 安装依赖

```bash
cd open-ai
npm install
```

### 2. 配置环境变量

```bash
# 复制环境变量模板
cp .env.example .env

# 编辑 .env 文件
# 使用你喜欢的编辑器打开 .env
```

`.env` 文件内容：

```bash
OPENAI_API_KEY=sk-proj-xxxxxxxxxxxxx
```

### 3. 验证配置

创建测试文件 `test-connection.ts`：

```typescript
import OpenAI from 'openai';
import dotenv from 'dotenv';

dotenv.config();

const openai = new OpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});

async function testConnection() {
  try {
    const response = await openai.chat.completions.create({
      model: 'gpt-3.5-turbo',
      messages: [{ role: 'user', content: 'Hello!' }],
      max_tokens: 10,
    });

    console.log('✅ 连接成功！');
    console.log('响应:', response.choices[0].message.content);
  } catch (error) {
    console.error('❌ 连接失败:', error);
  }
}

testConnection();
```

运行测试：

```bash
npx tsx test-connection.ts
```

## 📚 核心概念

### 1. Models（模型）

OpenAI 提供多个模型，各有特点：

| 模型 | 说明 | 适用场景 | 价格 |
|------|------|---------|------|
| **gpt-4o** | 最新多模态模型 | 复杂任务、图像理解 | 较高 |
| **gpt-4-turbo** | GPT-4 优化版 | 平衡性能与成本 | 中等 |
| **gpt-3.5-turbo** | 快速且经济 | 简单对话、测试 | 低 |
| **text-embedding-3-large** | 向量化模型 | 语义搜索、RAG | 低 |

### 2. Tokens

- **Token** 是 API 计费的基本单位
- 1 token ≈ 0.75 个英文单词
- 1 token ≈ 0.5 个中文字符
- 使用 [Tokenizer](https://platform.openai.com/tokenizer) 工具查看

示例：
```
"Hello, world!" → 4 tokens
"你好，世界！" → 6 tokens
```

### 3. Messages（消息）

对话由消息数组组成，每条消息有 `role` 和 `content`：

```typescript
const messages = [
  { role: 'system', content: '你是一个有帮助的助手' },  // 系统提示
  { role: 'user', content: '什么是 AI？' },            // 用户消息
  { role: 'assistant', content: 'AI 是...' },        // 助手回复
  { role: 'user', content: '请详细说明' },            // 继续对话
];
```

**角色说明**：
- `system`: 设定助手行为（可选但推荐）
- `user`: 用户输入
- `assistant`: AI 回复
- `function`/`tool`: 函数调用相关（高级功能）

### 4. Temperature（温度）

控制输出的随机性（0-2）：

- `0`: 确定性输出，适合事实性任务
- `0.7`: 平衡创造性与一致性（默认）
- `1.5+`: 高创造性，适合创意写作

## 🎯 第一个完整示例

创建 `demos/basic/first-chat.ts`：

```typescript
import OpenAI from 'openai';
import dotenv from 'dotenv';

dotenv.config();

const openai = new OpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});

async function firstChat() {
  console.log('🤖 发送请求到 OpenAI...\n');

  const completion = await openai.chat.completions.create({
    model: 'gpt-3.5-turbo',
    messages: [
      {
        role: 'system',
        content: '你是一个友好的 AI 助手，用简洁的语言回答问题。',
      },
      {
        role: 'user',
        content: '用一句话解释什么是机器学习？',
      },
    ],
    temperature: 0.7,
    max_tokens: 100,
  });

  const response = completion.choices[0].message.content;
  console.log('📝 AI 回复:', response);
  console.log('\n📊 使用统计:');
  console.log(`   - 输入 tokens: ${completion.usage?.prompt_tokens}`);
  console.log(`   - 输出 tokens: ${completion.usage?.completion_tokens}`);
  console.log(`   - 总计 tokens: ${completion.usage?.total_tokens}`);
}

firstChat().catch(console.error);
```

运行：

```bash
npx tsx demos/basic/first-chat.ts
```

## 🔍 参数详解

### 必需参数

- `model`: 使用的模型名称
- `messages`: 对话消息数组

### 常用可选参数

```typescript
{
  temperature: 0.7,        // 温度（0-2）
  max_tokens: 1000,        // 最大输出 tokens
  top_p: 1,                // 核采样（0-1）
  frequency_penalty: 0,    // 频率惩罚（-2 到 2）
  presence_penalty: 0,     // 存在惩罚（-2 到 2）
  stop: ['\n'],            // 停止序列
  n: 1,                    // 生成几个回复
  stream: false,           // 是否流式返回
}
```

## ⚠️ 常见错误

### 1. API Key 无效

```
Error: 401 Incorrect API key provided
```

**解决方案**：检查 `.env` 文件中的 API Key 是否正确

### 2. 速率限制

```
Error: 429 Rate limit exceeded
```

**解决方案**：
- 降低请求频率
- 升级付费计划
- 实现重试机制

### 3. Token 超限

```
Error: This model's maximum context length is 4096 tokens
```

**解决方案**：
- 减少输入文本长度
- 使用 `max_tokens` 限制输出
- 使用支持更长上下文的模型（如 gpt-4-turbo）
