# 安装指南

## 📦 快速安装（5 分钟）

### 步骤 1：准备图标（可选）

插件需要图标文件才能正常显示。有两种方式：

#### 方式 A：使用在线工具生成（推荐）

1. 打开 `icons/icon.svg` 文件
2. 访问 [CloudConvert](https://cloudconvert.com/svg-to-png)
3. 上传 `icon.svg`
4. 分别生成 16x16、32x32、48x48、128x128 四个尺寸
5. 下载并重命名为 `icon16.png`、`icon32.png`、`icon48.png`、`icon128.png`
6. 放到 `icons/` 目录

#### 方式 B：使用 ImageMagick（如果已安装）

```bash
cd chrome-extension/icons
convert -background none icon.svg -resize 16x16 icon16.png
convert -background none icon.svg -resize 32x32 icon32.png
convert -background none icon.svg -resize 48x48 icon48.png
convert -background none icon.svg -resize 128x128 icon128.png
```

#### 方式 C：跳过图标（临时方案）

- 如果暂时不想生成图标，插件仍可正常工作
- Chrome 会显示默认图标
- 后续可以随时添加图标

### 步骤 2：在 Chrome 中加载插件

1. **打开扩展管理页面**
   ```
   在地址栏输入：chrome://extensions/
   ```

2. **启用开发者模式**
   - 点击右上角的「开发者模式」开关

3. **加载插件**
   - 点击左上角「加载已解压的扩展程序」
   - 选择 `chrome-extension` 文件夹
   - 点击「选择」

4. **完成！**
   - 插件图标会出现在工具栏
   - 访问任意网页测试拦截效果

## 🎯 验证安装

### 测试 1：查看插件图标
- 工具栏应该出现插件图标
- 点击图标应该显示弹出窗口

### 测试 2：查看统计
- 点击插件图标
- 应该看到「今日拦截」和「总计拦截」统计

### 测试 3：测试拦截功能
1. 访问含有广告的网站（如新闻网站）
2. 打开浏览器控制台（F12）
3. 查看 Console 标签，应该看到：
   ```
   [ADB] 插件已加载
   [ADB] 已移除 X 个广告元素
   ```

### 测试 4：测试元素选择器
1. 点击插件图标
2. 点击「选择元素拦截」
3. 鼠标悬停在页面元素上应该出现红色高亮框
4. 点击元素应该将其移除并添加到拦截规则

## 🔧 故障排除

### 问题：插件无法加载

**可能原因 1：Chrome 版本过低**
- 解决方案：升级到 Chrome 88 或更高版本

**可能原因 2：manifest.json 语法错误**
- 解决方案：检查控制台错误信息

**可能原因 3：文件路径不正确**
- 解决方案：确保选择的是 `chrome-extension` 文件夹

### 问题：图标不显示

**原因**：缺少图标文件
- 解决方案：按照「步骤 1」生成图标
- 临时方案：插件功能不受影响，只是显示默认图标

### 问题：拦截不生效

**检查清单**：
1. ✅ 插件是否已启用？
2. ✅ 是否刷新了页面？
3. ✅ 是否在白名单中？
4. ✅ 打开控制台查看是否有错误？

### 问题：统计数据为 0

**原因**：
- 某些广告可能在请求发出前就被拦截
- 页面本身可能没有广告

**验证方法**：
1. 访问已知有广告的网站（如视频网站）
2. 查看控制台日志
3. 检查网络请求是否被拦截

## 📱 在其他浏览器中使用

### Microsoft Edge

1. 打开 `edge://extensions/`
2. 启用「开发人员模式」
3. 点击「加载解压缩的扩展」
4. 选择 `chrome-extension` 文件夹

### Brave Browser

1. 打开 `brave://extensions/`
2. 启用「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择 `chrome-extension` 文件夹

### Opera

1. 打开 `opera://extensions`
2. 启用「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择 `chrome-extension` 文件夹
